# Contributing

Issues, bug reports, and design discussions are welcome.

Do not submit a code or documentation contribution unless the repository owner
has first confirmed the applicable contributor agreement in writing. The
project uses both noncommercial public licensing and separate commercial
licensing, so accepting third-party copyrighted work requires terms that allow
the repository owner to continue both licensing models.

Opening a pull request by itself does not transfer copyright or grant the
repository owner commercial relicensing rights. Pull requests without the
required contributor agreement may be closed without merge.
